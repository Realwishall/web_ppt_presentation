Far Point

Fixing

If someone far point is not infinity but something like 250 cm

Normal eye

Far point = ∞  →  distant objects are seen clearly.

This eye

Far point = 250 cm = 2.5 m  →  anything beyond 2.5 m looks blurred.

So what has to be done

The lens must bring an object at infinity to form its image at the eye’s own far point, 250 cm — the farthest place this eye can still see clearly.

Near point

Fixing

If someone near point is not 25 but something like 50 cm

Normal eye

Near point = 25 cm  →  close objects are seen clearly.

This eye

Near point = 50 cm  →  anything nearer than 50 cm looks blurred.

So what has to be done

The lens must take an object kept at the normal 25 cm and form its image at this eye’s own near point, 50 cm — the closest place this eye can still see clearly.

We are fixing

Near point  ·  Convex lens

Near point has shifted away from the eye, so rays from a close object would meet behind the retina. A converging (convex) lens is placed in front of the eye.

DefectWithout lens
Rays converge beyond the retina → blurred image.
CorrectedWith convex lens
The convex lens converges rays first → focus lands on the retina.

We are fixing

Far point  ·  Concave lens

Far point has come closer than infinity, so rays from a distant object meet before the retina. A diverging (concave) lens is placed in front of the eye.

DefectWithout lens
Rays converge in front of the retina → blurred image.
CorrectedWith concave lens
The concave lens spreads rays first → focus moves back onto the retina.
