Mechanics Part 1

Constant velocity problem

v = dt
d = v t
t = dv

The speed never changes, so these are not three formulas — they are one relation rearranged. Every question on the boards that follow is find d or find t.

Question
A train is of length 200m is traveling with speed 20m/s as shown in the figure find time in which it will cross the pole.
Solution
t = dv the pole is a point — d is just the train's own length
t = 20020
t = 10 s
Question
A train is of length 200m is traveling with speed 20m/s as shown in the figure find time in which it will cross the bridge.
Solution
d = 200 + 60 = 260 the tail only clears the bridge after the whole train has passed it
t = 26020
t = 13 s
Question
In what time these train can cross each other if length of each train is 200m.
Solution
d = 200 + 200 = 400 nose of A must travel past the whole of B, and B past the whole of A
Vr = Va + Vb they run at each other — cross case
t = 40050 + 30
t = 5 s
Question
In what time driver of train A will cross driver of train B.
Solution
d = 200 A's driver only has to reach B's driver — one train length
Vr = Va − Vb same direction — overtake case
t = 20050 − 30
t = 10 s

Overtake VS cross case

Vr = Va + Vb
Vr = Va − Vb

Driver VS guard

The driver sits at the front, the guard at the tail — so "driver crosses the guard" is one full train length apart, while driver to driver is another.

Up stream – Down stream

Down stream the current carries you, so the speeds add; up stream you push against it, so they subtract. Same two cases as the trains, on water.

Question
It take t1 time to cover distance in down stream and t2 in up stream find in what time same distance can be covered Tough
Solution
v → Boat velocity
u → River velocity
t1 = dv + u
down stream — the river helps
t2 = dv − u
up stream — the river fights
t = dv
what we are asked for — no current at all
v + u = dt1
v − u = dt2
2v = dt1 + dt2 add the two — u cancels itself out
2vd = 1t1 + 1t2
2t = 1t1 + 1t2
Question
It take t1 time to go up when only escalator is moving upwards and t2 if only boy is walking upwards in what time same person can go up if we walk on escalator moving upwards? Tough
Solution
t1 = dv — escalator only
t2 = du — boy only
t = dv + u — both together
t = ddt1 + dt2 write each speed as its own distance over its own time
t = 11t1 + 1t2 d divides out — the answer never needed it
t = t1 t2t1 + t2
Question
It take t1 time to go up when only escalator is moving upwards and t2 if only boy is walking upwards in what time same person can go up if we walk on escalator moving upwards? Tough
Solution
t1 = dv — escalator only
t2 = du — boy only
Vr = u − v this time the two are set against each other
t = du − v

Nothing new is being done here — it is the overtake case of the very first board. Turn the escalator around and the same two speeds subtract instead of adding, so the boy takes longer, and if u ever drops to v he never gets to the top at all.
