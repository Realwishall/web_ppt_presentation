Proof of v=u+at

For acceleration we know that
  1. ⇒a=dvdt
  2. ⇒dv=a*dt
  3. Now ∫ both side
  4. ⇒∫uvdv=∫0tadt
  1. ⇒∫uvdv=a∫0tdt
  2. ⇒[v]uv=a[t]ot
  3. ⇒v−u=at
  4. ⇒v=u+at

Proof of s=ut+12at2

For Velocity we know that
  1. ⇒v=dxdt
  2. ⇒dx=v*dt
  3. Now ∫ both side
  4. ⇒∫xinitialxfinaldx=∫0t(u+at)dt
  1. ⇒xf−xi=u∫0tdt+a∫0ttdt
  2. ⇒s=ut+12at2

Proof of v2=u2+2as

For acceleration we know that
  1. ⇒a=vdvdx
  2. ⇒vdv=a*dx
  3. Now ∫ both side
  1. ⇒∫uVvdv=a∫xinitialxfinaldx
  2. ⇒v2−u22=as
  3. ⇒v2=u2+2as
