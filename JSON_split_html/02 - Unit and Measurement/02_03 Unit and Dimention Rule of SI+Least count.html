Unit and Measurement

Rule of SI

Unit in lower case

m, g, s — the symbol is written in small letters.

Upper case unit if on some scientist name

C, N, Pa, Wb, K

Coulomb, Newton, Pascal, Weber, Kelvin — the person gives the capital.

No plural unit

✗ Length of a rod is 10 ms

✓ Length of a rod is 10 m — a unit never takes an ‘s’.

No more than one solidus

✗ N/m/s/t

✓ N/(m s t) — one slash only; after that use brackets or negative powers.

Prefix without space

ms This is milli second
m s This is meter second — the space turned a prefix into a product.

Least Count

Least Count

The smallest value an instrument's scale can actually measure. Below it the instrument tells you nothing — you are estimating, not measuring.
