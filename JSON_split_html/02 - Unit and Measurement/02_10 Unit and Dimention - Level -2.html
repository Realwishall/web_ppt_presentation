General method question

The recipe Do not jump to a formula. Compute the value, then compute the largest value the expression can take, and subtract.
1 z ← put every variable at its mean value
2 zmax ← push each variable the way that makes z biggest
3 Δz = zmax − z
Which way to push A variable that increases z (numerator, positive term) → take its maximum.
A variable that decreases z (denominator, negative term) → take its minimum.

General method · product

Question If z = xy,  x = 10 ± 1,  y = 10 ± 2.  Find the absolute error in z.
Solution
z = xy = 10 × 10 = 100
zmax = 11 × 12 = 132 both in the numerator → both taken maximum
Δz = 132 − 100 = 32

General method · sum

Question If z = x + 3y,  x = 10 ± 1,  y = 10 ± 2.  Find the absolute error in z.
Solution
z = x + 3y = 10 + 3 × 10 = 40
zmax = 11 + 3 × 12 = 11 + 36 = 47
Δz = 47 − 40 = 7
Check Δz = Δx + 3Δy = 1 + 3 × 2 = 7   — the coefficient multiplies the error too.

General method · difference

Question If z = 3x − y,  x = 10 ± 1,  y = 10 ± 2.  Find the absolute error in z.
Solution
z = 3x − y = 3 × 10 − 10 = 20
zmax = 3 × 11 − 8 = 33 − 8 = 25 y carries a minus sign → take y minimum
Δz = 25 − 20 = 5
Galti mat karna In a subtraction the errors still add — they never cancel. Δz = 3Δx + Δy = 3 + 2 = 5

General method · quotient

Question If z = 3xy,  x = 33 ± 3,  y = 11 ± 2.  Find the absolute error in z.
Solution
z = 3 × 3311 = 9
zmax = 3 × 369 = 12 numerator maximum, denominator minimum
Δz = 12 − 9 = 3

General method · quotient again

Question If z = x / y,  x = 10 ± 2,  y = 5 ± 1.  Find the absolute error in z.
Solution
z = 105 = 2
zmax = 124 = 3
Δz = 3 − 2 = 1
Cross‑check Δzz = Δxx + Δyy = 0.2 + 0.2 = 0.4 ⇒ Δz = 0.8 — the formula is only the first‑order approximation, so it runs a little small.

Error in a trigonometric function

Question If y = sin θ, find the absolute error in y.
Solution
dydθ = cos θ
dy = cos θ · dθ
Δy = |cos θ| · Δθ error can never be negative → take the magnitude
Two things to remember Δθ must be in radian.  And the log‑differentiation shortcut fails here — sin θ is not a product of powers, so differentiate directly.

Matrix approach

testing whether a set of quantities can be fundamental

Which set can be fundamental?

Question Which of the following can act as a set of fundamental quantities?  Write the M L T powers as a 3×3 matrix. The set works only if det ≠ 0 — a zero determinant means one quantity is derivable from the other two, so they are not independent.
□ Length, area, velocity
MLT
010 020 01−1 = 0
□ Force, acceleration, mass
MLT
11−2 01−2 100 = 0
✔ Velocity, force, time
MLT
01−1 11−2 001 = −1 ≠ 0
□ Momentum, velocity, mass
MLT
11−1 01−1 100 = 0
Answer Only velocity, force and time are dimensionally independent.

Semi‑vertical angle and solid angle

Given The semi‑vertical angle θ of a cone. Find the solid angle it subtends at the apex.
Result Ω = 2π (1 − cos θ)
measured in steradian (sr)
Sanity check θ = 90° → Ω = 2π  (a hemisphere)
θ = 180° → Ω = 4π  (the whole sphere)

Length of the rod · with zero error

Question Find the length of the given rod. The least count of the instrument is 0.1 mm.
Observed reading = 2 mm + 5 × 0.1 mm
= 2.5 mm
Zero error = −1 mm + 9 × 0.1 mm
= −0.1 mm
True length R = observed − zero error
= 2.5 − (−0.1) = 2.6 mm

Note for JEE

Least count L.C. = | MSD − VSD |
the difference of one main‑scale and one vernier‑scale division — whichever way round they are.
Use this for the reading Reading = (some) MSD − (some) VSD − Error
Why the minus Count the main‑scale divisions up to the coinciding vernier line, then subtract the vernier divisions you counted past the zero. It works even when the vernier runs backwards.

Angular MSD and VSD

The setting On a spectrometer the scales are marked in degrees, not millimetres. Nothing changes — the least count is still one MSD minus one VSD.
Typical data 1 MSD = 0.5° = 30′  ·  30 VSD = 29 MSD
Solution
1 VSD = 2930 MSD
L.C. = 1 MSD − 1 VSD = 130 MSD = 30′30 = 1′
Reading it off If the main scale reads 30.5° and the 12th vernier line coincides,
θ = 30.5° + 12 × 1′ = 30° 30′ + 12′ = 30° 42′

When MSD is smaller than VSD

The trap Students write L.C. = MSD − VSD and get a negative least count. The least count is a size — it is always the magnitude of the difference.
Question 9 VSD = 10 MSD, and 1 MSD = 1 mm. Find the least count.
Solution
1 VSD = 109 MSD = 1.11 mm  — bigger than one MSD
L.C. = | 1 − 109 | MSD = 19 mm ≈ 0.11 mm
Consequence With VSD larger than MSD the vernier scale runs backwards — count the coinciding division from the right, and the vernier part subtracts from the main‑scale reading.

Zero error in a screw gauge

No error When the jaws touch, the 0 of the circular scale sits exactly on the reference line. The instrument is correct.
Positive error The 0 of the circular scale is below the line.
True = Observed − (+ e)
Negative error The 0 of the circular scale is above the line.
True = Observed − (− e) = Observed + e
One rule for both True reading = Observed − Zero error  (with sign)

Which quantity can be the answer?

Question ℓ, v, a, t and m are given quantities with the dimensions of length, velocity, acceleration, time and mass.
If the answer must be a length (a) at    (b) mvt    (c) √(aℓ)    (d) v/t    (e) v2/a ✔
v2/a = (L2T−2) / (LT−2) = L
If the answer must be a time (a) a/t    (b) mv/ℓ    (c) v2/a    (d) √(ℓ/a) ✔    (e) √(v/a)
√(ℓ/a) = √(L / LT−2) = √(T2) = T
If the answer must be a force (a) mv2    (b) mat    (c) mv/t ✔    (d) mv/ℓ    (e) v2/ℓ
mv/t = M · LT−1 / T = MLT−2

Significant digits · in a subtraction

Question How many significant digits are there in 4.24 × 10−4 − 2.0 × 10−5 ?
Solution
⇒ (4.24 − 0.20) × 10−4 first bring both to the same power of ten
⇒ 4.04 × 10−4
Answer Both terms carry 2 decimal places, so the result keeps 2 decimal places → 3 significant digits
