Measurement & Error

order of magnitude · significant figures · error analysis

Order of magnitude

The rule Write the number as a × 10b  where  0.5 ≤ a < 5. Then b is the order of magnitude.
3.7 × 1011 order = 11
7.7 × 1011 = 0.77 × 1012 order = 12
50 = 0.5 × 102 order = 2
Notice 7.7 is not less than 5 — so it must first be pushed into the 0.5 – 5 window, and the order goes up by one.

Round off

If the digit to the right of the last digit you want to keep is less than 5, simply drop all the digits to the right.
If that digit is greater than 5 (or 5 followed by something), add 1 to the last remaining digit, then drop the rest.
Galti mat karna If that digit is exactly 5 and nothing follows it — look at the last remaining digit.
Even → simply drop.   Odd → increment it.
3.71⟶3.7
3.66⟶3.7
3.75⟶3.8
3.85⟶3.8
3.854⟶3.9

Parallax method

Used for Measuring very large lengths — up to about 100 light years.
Angle θ = arcradius   θ must be in radian
If the angle is in D·M·S θ = 4°2′6″
use = (4 + 260 + 63600) π180

Significant figures · the rules

  • All non‑zero digits are significant.
  • Zeros between non‑zero digits are significant.
  • Right‑side zeros without a decimal point are not significant.
  • Right‑side zeros with a decimal point are significant.
  • Left‑side (leading) zeros are never significant.
  • The power of 10 does not matter.
  • Fixed digits and counted numbers have ∞ significant figures.
Note If an integer is written without any unit and you have no idea about it, assume it is a count.

Significant figures · in calculation

In + and − Keep the least decimal place
3.1507 + 3.2 = 6.3507 = 6.4
In × and ÷ Keep the least significant figure
3.6507 × 3.3 = 12.04731 = 12
Note If a calculation can be done by addition, it will be done by addition only.
Vocabulary The last significant digit is also called the uncertain digit.

Part 2
Errors in measurement

positive & negative · random · systematic

Positive and negative error

Positive error The measured value comes out more than the true value.
Negative error The measured value comes out less than the true value.
Two families Random error — sign and size keep changing  ·  Systematic error — same sign and size every time.

Random error

Definition If the error’s magnitude and sign can change randomly from reading to reading.
Sources
  • Any random fluctuation
  • Least count error
Key result Random error ∝ 1number of observations

Systematic error

Definition If the error has the same magnitude and same sign in every reading.
Instrumental error Zero error — an empty weighing machine already showing 5 kg.
Personal error Comes from a habit — like parallax while reading a scale.
Imperfect technique The method itself is not right for the job.
Backlash error Lash or play in the screw threads — cannot be removed completely.

Question · the difference that matters

Question Random error in 50 readings is x. Find the random error in 150 readings.
Solution error ∝ 1N  →  xx′ = 15050
x′ = x3
Question Zero error in 50 readings is x. Find the zero error in 150 readings.
Solution Zero error is systematic — same in every single reading.
error = x
Takeaway More readings kill random error. They do nothing to a systematic one.
Part 3
Calculating error

mean value · absolute · relative · percentage

Mean value

Let the length of a rod be l = 3.77 m, 3.75 m, 3.73 m
Mean ⇒ lmean = 3.77 + 3.75 + 3.733
So ⇒ lmean = 3.75 m

Mean absolute error

Same rod l = 3.77 m, 3.75 m, 3.73 m  ·  lmean = 3.75 m
Step 1 ⇒ Δlmean = |3.75 − 3.77| + |3.75 − 3.75| + |3.75 − 3.73|3
Step 2 ⇒ Δlmean = 0.02 + 0 + 0.023 = 0.043
Report it as ⇒ l = 3.75 ± 0.043 m
Note Error is always taken positive — that is why the modulus is there.

Four names for one idea

l length — the measured value
Δl absolute error · uncertainty · gross error · permissible error
Δll relative error · fractional error
Δll × 100 percentage error

Question

Question I = 200 ± 3  ·  find the absolute error, the relative error and the percentage error.
Absolute error = 3
Relative error = 3200 = 0.015
Percentage error = 0.015 × 100 = 1.5%

When the error is not given

Rule 1 If the error is not given, the least count of the instrument becomes the error.
A stop watch has a least count of 0.2 s and it measures 17 s → the reading is 17 ± 0.2 s
Rule 2 If the least count is also not given, the error is 1 at the last significant place.
3.09⟶3.09 ± 0.01
3.0900⟶3.0900 ± 0.0001

Warning question

Question The least count of a stop watch is 1 second. The time of 20 oscillations of a pendulum is measured to be 25 seconds.
Solution

The trap Dividing by 20 shrinks the absolute error — but the relative and percentage error do not change.
Part 4
Combination of errors

sum & difference · product & quotient · large errors

Error combination · important

General method
  • Find the value
  • Then find the maximum value
  • The difference is the absolute error
Addition and subtraction Absolute errors add up, using the same formula.
Multiplication and division For a small change (less than 5%), percentage errors add up.
General method for small change Use differentiation.

Sum and difference · question

Question If z = 3x − y,   x = 10 ± 1,   y = 10 ± 2.
Solution Δz = 3Δx + Δy
Δz = 3 × 1 + 2
Δz = 5
So z = 20 ± 5   the minus sign in the formula never subtracts errors — they always add

Sum and difference · question

Question A rod of length l = 30 ± 1, out of which he sold 10 ± 2. The remaining length will be?
Solution l = (30 ± 1) − (10 ± 2)
l = 20 ± 3
Remember Value subtracts. Error still adds.

Multiplication & division · question

Question If the % error in R is 2% and in I it is 3%, find the percentage error in voltage.
Short way V = IR
δV = δI + δR
δV = 2 + 3 = 5%
Or the long way ΔVV = ΔII + ΔRR
ΔVV×100 = ΔII×100 + ΔRR×100 = 5%

Multiplication & division · question

Question If the % error in m1 is 2%, in m2 it is 3% and 1% in distance, find the percentage error in force.   F = Gm1m2r2
Solution δF = δm1 + δm2 + 2δr
δF = 2 + 3 + 2 × 1
δF = 7%
Or ΔFF = Δm1m1 + Δm2m2 + 2Δrr
a power in the formula becomes a multiplier on the percentage error

Multiplication & division · question

Question If the % error in m is 1% and in v it is 3%, find the percentage error in momentum.
Solution P = mv
δP = δm + δv = 1 + 3
δP = 4%

Multiplication & division · question

Question If the % error in m is 1% and in v it is 3%, find the percentage error in kinetic energy.
Solution K.E. = 12 mv2
δK.E. = δm + 2δv = 1 + 2 × 3
= 7%
Note The constant 12 is exact — it carries no error at all.

Multiplication & division · question

Question If P = a3b2√c·d and the % errors in a, b, c, d are 1%, 1%, 2% and 2%, find the percentage error in P.
Solution δP = 3δa + 2δb + 12δc + δd
= 3×1 + 2×1 + 12×2 + 2
= 8%
Pattern Power n → multiply that percentage error by n. A square root is just n = 12.

When the percentage error is large

Question If the % error in m is 10% and in v it is 20%, find the percentage error in momentum.
Tempting — and wrong δP = δm + δv = 10 + 20 = 30%
As the error is large, the additive shortcut breaks.
Using the general method ⇒ Pvalue = mv
⇒ Pmax = 1.1m × 1.2v = 1.32 mv
For percentage change use (n − 1) × 100
= 32%

When the percentage error is large

Question If the % error in velocity is 10%, find the percentage error in kinetic energy.
Using the general method ⇒ K.E. = 12 mv2
⇒ K.E.max = (1.1)2 times = 1.21 times
Percentage change (n − 1) × 100 = (1.21 − 1) × 100 = 21%   the shortcut would have said 20%

Proper error reporting

Question In an experiment to measure the focal length of an equiconvex lens, the following measurements were made: |u| = 0.30 cm, |v| = 0.60 cm. The image formed is real. The focal length of the lens within error limits is
(A) (0.20 ± 0.01) cm (B) (0.20 ± 0.02) cm
(C) (0.20 ± 0.0055) cm (D) (0.20 ± 0.005) cm
Value 1f = 1v − 1u  → f = 0.20 cm
Error Δff2 = Δuu2 + Δvv2
Δf = 0.04 × 0.1389 = 0.0055
Report it properly The measurement itself is known only to 2 decimal places — the error cannot be quoted more precisely than the value.
0.0055 ⟶ 0.01  so the answer is (A)

Question · absolute vs percentage

Question If diameter is 60 ± 2, then the radius is
  • 30 ± 2
  • 30 ± 1
Solution r = d2 → the absolute error is halved too.
30 ± 1
Question If diameter is 60 ± 2%, then the radius is
  • 30 ± 2%
  • 30 ± 1%
Solution Dividing by an exact 2 changes nothing in the ratio — the percentage error stays.
30 ± 2%

Note · for reciprocal sums

For this case ⇒ 1Reff = 1R1 + 1R2
The error goes ⇒ ΔReffReff2 = ΔR1R12 + ΔR2R22
Same formula works in 1f = 1v + 1u

Accuracy & precision

two different questions about the same reading

Accuracy and precision

Accuracy How close a set of measurements is to the true value.
Steps to check accuracy
  • First by percentage error
  • Then by absolute error
Precision How close or dispersed the measurements are to each other.
Steps to check precision
  • The number with more decimal places

Question

Question Which one is more accurate?
Solution — compare the percentage error
(A) 4.0 ± 0.1 (B) 400 ± 1 (C) 0.4 ± 0.1 (D) 40. ± 1
2.5% 0.25%  ✓ 25% 2.5%
Answer (B) 400 ± 1 — smallest percentage error, so the most accurate.

Minimizing error

In a calculation The quantity with the least magnitude must be kept the most accurate and most precise.
Why The same absolute error on a small number is a much bigger percentage error — and percentage errors are what add up.
Example 0.4 ± 0.1 = 25%  versus  400 ± 1 = 0.25% — same 0.1–1 sized slip, hundred‑fold difference.
