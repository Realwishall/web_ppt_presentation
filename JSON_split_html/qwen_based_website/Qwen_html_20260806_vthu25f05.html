Starting point

Reference frame & reference point

Reference frame — a coordinate system (a set of axes) with respect to which observations are made.

Reference point — the fixed point (origin) of the frame from which positions are measured.

Every quantity in mechanics — position, velocity, displacement — is meaningless until the frame is declared first.

Example

“A particle is at \((3,4,5)\)” means: 3 m along \(x\), 4 m along \(y\), 5 m along \(z\) — measured from the origin O of the chosen frame.

Starting point

Position — vector and polar form

Position of a particle = its location relative to the reference point, written as a vector.

Formula

Vector form: \(\vec r = x\hat i + y\hat j + z\hat k\)

Magnitude: \(|\vec r| = \sqrt{x^{2}+y^{2}+z^{2}}\)

2-D polar form: \((r,\theta)\) with \(r=\sqrt{x^{2}+y^{2}},\ \theta=\tan^{-1}\left(\frac{y}{x}\right)\)

Example

Particle at \((3,4,5)\):

\(|\vec r|=\sqrt{3^{2}+4^{2}+5^{2}}=\sqrt{50}\approx 7.07\ \mathrm{m}\)

Position needs both magnitude and direction — it is a vector. The same point has different coordinates in a different frame.

Starting point

Rest and motion are relative

A body is at rest if its position does not change with time relative to the reference point; it is in motion if the position changes.

Rest and motion are relative terms. The same body can be at rest in one frame and in motion in another.

Example

A passenger in a moving bus: at rest w.r.t. the bus, in motion w.r.t. the road.

Note

Even a “stationary” building moves with the Earth around the Sun — there is no absolute state of rest.

Path lengths

Distance — length of the actual path

Distance = total length of the actual path travelled. It is a scalar, depends on the path, and can never decrease as time passes. SI unit: metre.

Question

A boy travels 4 m north, then 3 m east. Find the distance travelled.

Solution

Distance = length of path actually walked:

\(s = 4 + 3 = 7\ \mathrm{m}\)

Warning: the answer is not 5 m. That straight-line value is the displacement — the next idea.

Path lengths

Distance on a curved path

Question

A body moves on a quarter-circle arc of radius \(R\). What distance does it cover?

Solution

Distance = arc length: \(s = \frac{1}{4}(2\pi R) = \frac{\pi R}{2}\)

Question

And along a half-circle of radius \(R\)?

Solution

\(s = \frac{1}{2}(2\pi R) = \pi R\)

On a curved path, distance (the arc) is always longer than the straight chord joining the ends.

Path lengths

Displacement — change in position

Formula

\[\Delta\vec r = \vec r_{f} - \vec r_{i}\]

Displacement is the change in position: a straight vector from the initial point to the final point.

It is a vector. It depends only on the endpoints — never on the path taken.

For any journey: \(|\Delta\vec r| \le\) distance. They are equal only for straight-line motion without turning back.

Note

A long journey can end with zero displacement — return to the start and \(\Delta\vec r = 0\).

Path lengths

Displacement — worked examples

Question

A body moves from \((3,4)\) to \((8,8)\). Find its displacement.

Solution

\(\Delta x = 8-3 = 5,\quad \Delta y = 8-4 = 4\)

\(|\Delta\vec r| = \sqrt{5^{2}+4^{2}} = \sqrt{41} \approx 6.40\ \mathrm{m}\), at \(\tan^{-1}\left(\frac{4}{5}\right) \approx 38.7\degree\) to the \(x\)-axis.

Question

A particle goes 3 m east, then 4 m west. Displacement?

Solution

Take east as positive: \(\Delta x = +3 - 4 = -1\ \mathrm{m}\) → 1 m west. Distance was 7 m; displacement is only 1 m.

Path lengths

Displacement — the 3-4-5 family

Question

A particle goes 3 m east, then 4 m north. Find displacement.

Solution

\(|\Delta\vec r| = \sqrt{3^{2}+4^{2}} = 5\ \mathrm{m}\), at \(\tan^{-1}\left(\frac{4}{3}\right) \approx 53\degree\) north of east.

Question

Now 3 m east, 4 m north, then 5 m up. Displacement?

Solution

\(|\Delta\vec r| = \sqrt{3^{2}+4^{2}+5^{2}} = \sqrt{50} = 5\sqrt{2} \approx 7.07\ \mathrm{m}\)

Path lengths

Displacement — the rolling wheel

Question

A wheel of radius \(R\) rolls forward half a rotation. Find the displacement of the marked point (initially touching the ground).

Solution
  • Horizontal shift of the point = half the circumference = \(\pi R\)
  • Vertical shift = one diameter = \(2R\) (bottom → top)
  • \(|\Delta\vec r| = \sqrt{(\pi R)^{2} + (2R)^{2}} = R\sqrt{\pi^{2}+4} \approx 3.72\,R\)

Bonus: the distance the point travels is the cycloid arc \(= 4R\), while its displacement is only \(\approx 3.72\,R\). Path ≥ straight line, as always.

Rates

Velocity and speed

Formula

Velocity = rate of change of position: \(\vec v = \frac{d\vec r}{dt}\) — a vector.

Speed = magnitude of velocity: \(v = |\vec v| = \frac{ds}{dt}\) — a scalar, always \(\ge 0\).

Instantaneous velocity = velocity at a single instant (\(\Delta t \to 0\)). What a speedometer reads is the instantaneous speed.

Constant velocity

Equal displacements in equal time intervals:

\[\vec r(t) = \vec r_{0} + \vec v\,t \qquad\text{(1-D: } x = x_{0} + vt\text{)}\]

Velocity can be negative (direction); speed can never be negative.

Rates

Average velocity vs. average speed

Formula

Average velocity: \(\vec v_{av} = \frac{\Delta\vec r}{\Delta t}\)  (vector)

Average speed: \(= \frac{\text{total distance}}{\text{total time}}\)  (scalar)

\(|\vec v_{av}| \le\) average speed — always. They are equal only for straight-line motion without turning back.

Example

Round trip A → B → A in time \(t\): displacement = 0 ⇒ \(\vec v_{av} = 0\), but average speed \(= \frac{2\cdot AB}{t} > 0\).

Rates

Two classic averages: same time, same distance

Same time

Speeds \(v_{1}\) and \(v_{2}\), each for time \(t\):

\[v_{av} = \frac{v_{1}t + v_{2}t}{2t} = \frac{v_{1}+v_{2}}{2}\]

the arithmetic mean

Same distance

Speeds \(v_{1}\) and \(v_{2}\), each for distance \(d\):

\[v_{av} = \frac{2d}{\frac{d}{v_{1}}+\frac{d}{v_{2}}} = \frac{2v_{1}v_{2}}{v_{1}+v_{2}}\]

the harmonic mean — smaller than the arithmetic mean

Quick check

With \(v_{1}=30,\ v_{2}=60\): same time → \(45\ \mathrm{m/s}\); same distance → \(40\ \mathrm{m/s}\). The slower half costs more time, so it drags the average down.

Rates

Practice — mixed average speed I

Question

A body travels with speed \(90\ \mathrm{m/s}\) for half the distance. In the remaining half distance, it moves at \(20\ \mathrm{m/s}\) for half the time and at \(40\ \mathrm{m/s}\) for the other half of the time. Find its average speed.

Solution
  • Second half, equal times: average \(= \frac{20+40}{2} = 30\ \mathrm{m/s}\).
  • Let total distance be \(D\): \(t_{1} = \frac{D/2}{90} = \frac{D}{180}\), \(t_{2} = \frac{D/2}{30} = \frac{D}{60}\).
  • Total time \(= \frac{D}{180} + \frac{D}{60} = \frac{4D}{180} = \frac{D}{45}\).
  • \(v_{av} = \frac{D}{D/45} = 45\ \mathrm{m/s}\).

Strategy: collapse each part into one distance and one time, then use \(\frac{\text{total distance}}{\text{total time}}\). Never average speeds blindly.

Rates

Practice — mixed average speed II

Question

A body travels with speed \(80\ \mathrm{m/s}\) for half the total time. During the remaining half of the time, it covers half of that distance at \(30\ \mathrm{m/s}\) and the remaining half distance at \(60\ \mathrm{m/s}\). Find its average speed.

Solution
  • Second interval, equal distances: average \(= \frac{2 \times 30 \times 60}{30+60} = 40\ \mathrm{m/s}\).
  • Now the whole journey is two equal-time parts: \(80\ \mathrm{m/s}\) and \(40\ \mathrm{m/s}\).
  • \(v_{av} = \frac{80+40}{2} = 60\ \mathrm{m/s}\).

Two different tools, chained: harmonic mean inside, arithmetic mean outside. Identify what is equal (time or distance) at each stage.

Changing velocity

Acceleration

Formula

Acceleration = rate of change of velocity:

\[\vec a = \frac{d\vec v}{dt} \qquad \vec a_{av} = \frac{\Delta\vec v}{\Delta t}\]

Unit: \(\mathrm{m/s^{2}}\). It is a vector.

Example

Velocity changes from \(10\) to \(30\ \mathrm{m/s}\) in \(4\ \mathrm{s}\): \(a = \frac{30-10}{4} = 5\ \mathrm{m/s^{2}}\) (uniform).

Example

From \(20\) to \(5\ \mathrm{m/s}\) in \(3\ \mathrm{s}\): \(a = \frac{5-20}{3} = -5\ \mathrm{m/s^{2}}\) — the speed is dropping.

Acceleration tells how velocity changes — not which way the body moves.

Changing velocity

Average acceleration is a vector

Question

A particle moves at \(3\ \mathrm{m/s}\) east. After \(3\ \mathrm{s}\), its velocity is \(4\ \mathrm{m/s}\) north. Find the average acceleration.

Solution

\(\Delta\vec v = \vec v_{f} - \vec v_{i}\): components \((-3\) east, \(+4\) north\()\), so \(|\Delta\vec v| = \sqrt{3^{2}+4^{2}} = 5\ \mathrm{m/s}\).

Direction: \(53\degree\) north of west. Hence

\(\vec a_{av} = \frac{\Delta\vec v}{\Delta t} = \frac{5}{3} \approx 1.67\ \mathrm{m/s^{2}}\), along \(\Delta\vec v\).

Subtract the vectors, not the speeds: \(|\Delta\vec v| = 5\), not \(4-3 = 1\).

Changing velocity

Direction of average acceleration

Question

A particle’s velocity changes from \(4\ \mathrm{m/s}\) east to \(4\ \mathrm{m/s}\) north. Find the direction of the average acceleration.

Solution

\(\Delta\vec v = \vec v_{f} - \vec v_{i} = (-4,\ +4)\) — it points north-west, \(45\degree\) north of west.

\(\vec a_{av}\) is along \(\Delta\vec v\) ⇒ direction is north-west. Magnitude: \(|\Delta\vec v| = 4\sqrt{2} \approx 5.66\ \mathrm{m/s}\).

Equal speeds do not mean zero acceleration — the direction changed, so the velocity changed.

Changing velocity

Retardation vs. negative acceleration

Retardation (deceleration): the speed is decreasing — velocity and acceleration point in opposite directions.

Negative acceleration: simply acceleration along the chosen negative axis. The speed may be increasing or decreasing!

The sign of \(a\) alone tells you nothing about speeding up or slowing down. Compare the directions of \(\vec v\) and \(\vec a\).

velocityaccelerationspeed…retardation?
\(+\)\(+\)increasesNo
\(+\)\(-\)decreasesYes
\(-\)\(-\)increasesNo
\(-\)\(+\)decreasesYes
Rule

Retardation ⇔ \(\vec v\) and \(\vec a\) opposite. Rows 2 and 4 — one of them has negative acceleration with increasing speed… no: rows 3 shows negative \(a\) with increasing speed.

Vocabulary

Types of motion & the language of time

Uniform motion — velocity is constant.

Non-uniform motion — velocity is changing.

Uniformly accelerated motion — acceleration is constant.

English matters

“in 3 s” → interval \(0 \to 3\ \mathrm{s}\)  ·  “in the 3rd second” → interval \(2 \to 3\ \mathrm{s}\)
“at \(t = 3\ \mathrm{s}\)” → an instant  ·  “in the 3rd half second” → interval \(1.0 \to 1.5\ \mathrm{s}\)

An interval has duration; an instant does not. “Distance in the nth second” means the distance between \(t = n-1\) and \(t = n\).

Vocabulary

Terminal velocity · reaction time · sign convention

Terminal velocity — the final constant velocity reached when the acceleration becomes zero (e.g. a falling body when air drag balances weight).

Reaction time — the delay between seeing a situation and acting on it. During this time the system can make no change: a car at speed \(v\) still travels \(v\,t_{r}\). Typical human value \(\approx 0.2\ \mathrm{s}\).

Sign convention — choose one direction as positive; the opposite direction is negative. With “up” positive, gravity is \(g = -9.8\ \mathrm{m/s^{2}}\).

Why it matters

In every problem: fix the sign convention first, then substitute \(u, v, a, g\) with signs. Most “wrong answers” in kinematics are sign errors.

Concept check

Question

The speed of a particle is increasing. Which of the following must be true?

AThe velocity is positive.
BThe acceleration is positive.
CThe velocity and acceleration are in the same direction.
DThe acceleration is constant.
Answer — C

Speed rises only when \(\vec a\) points along \(\vec v\). “Positive” depends on which axis we chose; same direction does not. If the speed were decreasing, they would be opposite.

Relative motion

Relative velocity in 1-D

Formula

\[\vec v_{AB} = \vec v_{A} - \vec v_{B}\]

Velocity of A as seen by B.

Same direction → relative speed \(= |v_{A} - v_{B}|\)
Opposite directions → relative speed \(= v_{A} + v_{B}\)

Time to meet \(= \frac{\text{separation}}{\text{relative speed of approach}}\). In the frame of B, only \(\vec v_{AB}\) exists.

Relative motion

When will they meet? (60 m apart)

Case A — opposite directions

A and B are 60 m apart. A moves toward B at \(10\ \mathrm{m/s}\), B toward A at \(20\ \mathrm{m/s}\). When do they meet?

Solution

Approach speed \(= 10 + 20 = 30\ \mathrm{m/s}\) ⇒ \(t = \frac{60}{30} = 2\ \mathrm{s}\) (20 m from A).

Case B — same direction

A chases B from 60 m behind: A at \(15\ \mathrm{m/s}\), B at \(5\ \mathrm{m/s}\). When does A catch B?

Solution

Approach speed \(= 15 - 5 = 10\ \mathrm{m/s}\) ⇒ \(t = \frac{60}{10} = 6\ \mathrm{s}\).

Relative motion

Two stones — when do they collide?

Question

A stone is thrown vertically up from the ground at \(40\ \mathrm{m/s}\). At the same instant, another stone is dropped from the top of an \(80\ \mathrm{m}\) tower. When and where do they meet? \((g = 10\ \mathrm{m/s^{2}})\)

Solution
  • Both have the same acceleration \(g\) ⇒ the relative velocity stays constant \(= 40\ \mathrm{m/s}\) (approach).
  • Separation \(80\ \mathrm{m}\) ⇒ \(t = \frac{80}{40} = 2\ \mathrm{s}\).
  • Height: \(y = 40(2) - \frac{1}{2}(10)(2^{2}) = 80 - 20 = 60\ \mathrm{m}\) above ground.

Gravity cancels in relative motion — solve it as uniform motion of one stone relative to the other.

Getting a feel

Feel for the terms — comparisons

Question

Compare distance and displacement. When can they be equal?

Answer

Distance = actual path length (scalar, only grows). Displacement = change in position (vector, can shrink or be zero). Equal in magnitude only for straight-line motion without turning back.

Question

Compare average speed and average velocity. When can they be equal?

Answer

Average speed \(=\) total distance / time; average velocity \(=\) displacement / time. Average speed \(\ge |\vec v_{av}|\) always — equal under the same condition: straight path, no reversal.

Getting a feel

Feel for the terms — possible or not?

Question

Velocity never zero, yet displacement zero?

Yes

One full round of uniform circular motion: \(v \ne 0\) throughout, but you return to the start.

Question

Velocity never zero, yet average velocity zero?

Yes

Any closed-loop trip: \(\Delta\vec r = 0\) ⇒ \(\vec v_{av} = 0\).

Question

Velocity zero, yet acceleration non-zero?

Yes

At the top of a vertical throw: \(v = 0\) for an instant, but \(a = g\) downward all along.
