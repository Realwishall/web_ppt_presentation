Functions, Limits, and Differentiation

What is a function f(x)?

If f(x) = x², Find f(2)

f(2) = 2² = 4

If f(x) = sin(x), Find f(30°)

f(30°) = sin(30°) = 1/2

If f(x) = eˣ, Find f(0)

f(0) = e⁰ = 1

If f(x) = cos x + eˣ, Find f(0)

f(0) = cos 0 + e⁰ = 1 + 1 = 2

Differentiation Terms

Δx ⇒ Change in x ⇒ x_final − x_initial

d ⇒ very small change

Example: t = 1s, V = 2m³  →  t = 3s, V = 5m³

Δt = 2s,   ΔV = 3m³,   ΔV/Δt = 3/2

If we take a very small time, it will be dt and change in volume will be dV.

dV/dt is called the rate of change of volume with respect to time.

If y = x³ + x² and x changes from 2 to 5:

Initial value of x: 2

Final value of x: 5

Change in x: 5 − 2 = 3

Initial value of y: 2³ + 2² = 8 + 4 = 12

Final value of y: 5³ + 5² = 125 + 25 = 150

Change in y: 150 − 12 = 138

Differentiation Rules

Constant Multiple: d/dx (a × v) = a d(v)/dx

y = 3x² → dy/dx = 6x

y = 4x³ → dy/dx = 12x²

y = 4 sin(x) → dy/dx = 4 cos(x)

Sum/Difference: d/dx (v + u) = d(v)/dx + d(u)/dx

y = x³ + sin x → dy/dx = 3x² + cos x

y = 4x³ + eˣ → dy/dx = 12x² + eˣ

Product Rule: d/dx (v × u) = d(v)/dx u + d(u)/dx v

y = x² sin x → dy/dx = 2x sin x + x² cos x

y = sin x ln(x) → dy/dx = cos(x) ln(x) + (1/x) sin(x)

Quotient Rule: d/dx (v/u) = [d(v)/dx u − d(u)/dx v] / u²

y = x² / sin x → dy/dx = [2x sin x − x² cos x] / sin² x

Chain Rule & Higher Order Derivatives

Chain Rule

y = f(g(x)) → dy/dx = f'(g(x)) × g'(x)

y = sin(x²) → dy/dx = cos(x²) × 2x

y = ln(x³ + 4) → dy/dx = 1/(x³ + 4) × 3x²

Higher Order Derivatives

If y = x⁴:

dy/dx = 4x³

d²y/dx² = 12x²

d³y/dx³ = 24x

d⁴y/dx⁴ = 24

Partial & Implicit Differentiation

Partial Differentiation

When differentiating w.r.t x, assume y and z as constant.

If K = 3x² y z³:

∂K/∂x = 3yz³ × 2x = 6xyz³

∂K/∂y = 3x²z³ × 1 = 3x²z³

∂K/∂z = 3x²y × 3z² = 9x²yz²

Differentiation w.r.t another term

If y = f(x), then dy/dt = (dy/dx) × (dx/dt)

Example: y = x² → dy/dt = 2x (dx/dt)

Example: A = 4πr² → dA/dt = 8πr (dr/dt)

Applications in Physics

Concept Formula
Current (rate of change of charge) i = dQ/dt
Temperature gradient Tg = dT/dx
Velocity (rate of change of position) v = dx/dt
Acceleration (rate of change of velocity) a = dv/dt
Example: Position s = 3t³ + 7t² + 14t + 8

Find velocity at t = 1 sec:

v = ds/dt = 9t² + 14t + 14

v(at t=1) = 9(1) + 14(1) + 14 = 37 m/s

Graphical Meaning of Slope

Average Slope

tan θ = Δy / Δx

This is NOT the instantaneous slope.

Instantaneous Slope

tan θ = dy / dx

This IS the slope.

Reading Data from a Graph

Find value of P at t = 3 ⇒ 12

a = P/t, Find value of a at t = 4 ⇒ 20 / 4 = 5

b = ΔP/Δt, Find value of b in 4th second ⇒ (20 − 12) / (4 − 3) = 8

c = dP/dt, Find value of c at t = 4 ⇒ tan 30°

Finding Maxima and Minima

For max or min: dy/dx = 0

Maxima

d²y/dx² = −ve

Minima

d²y/dx² = +ve

Example: y = x³/3 − 4x² + 12x + 24

dy/dx = x² − 8x + 12 = 0

Using quadratic formula: x = (8 ± √(64 − 48)) / 2 = (8 ± 4) / 2

So, x = 2 or x = 6

d²y/dx² = 2x − 8

At x = 2: d²y/dx² = 2(2) − 8 = −4 (Negative → Maxima)

At x = 6: d²y/dx² = 2(6) − 8 = 4 (Positive → Minima)

First differentiation gives Slope of curve.

Second differentiation gives Curvature of curve.
