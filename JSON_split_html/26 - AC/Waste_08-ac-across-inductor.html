Alternating Current · Part 8

AC Across an Inductor

A coil fights any change in current — that lag shows up as a 90° phase shift.

AC supply along L

  • Apply v=V0sinωt across an inductor L, using v=Ldidt
  • Integrating: i=V0ωLsin(ωt−π2)
  • So current lags the voltage by π/2 (90°)
  • Define inductive reactance XL=ωL — "something like resistance" for an inductor, unit ohm (Ω)
  • XL increases with frequency — at DC (f=0) an ideal inductor behaves like a plain wire

Mnemonic "VIL": in an inductor, V leads I (I lags V)
