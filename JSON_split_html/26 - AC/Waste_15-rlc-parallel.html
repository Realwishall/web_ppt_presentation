Alternating Current · Part 15

RLC Parallel Circuit

Same voltage across every branch now — so this time it's the currents that become vectors.

Treat currents as vectors

  • In parallel, the same voltage V appears across R, L, C — use it as the reference
  • IR is in phase with V
  • IL lags V by 90°; IC leads V by 90° — so IL and IC oppose each other
  • Resultant supply current: I=IR2+(IC−IL)2

Because IL and IC cancel at resonance, the source barely needs to supply any current from outside — the circuit rejects (blocks) that particular frequency, offering it very high impedance.

If it isn't stated…

  • If a question doesn't make clear whether elements are in series or parallel, the default assumption is series
  • Power is still lost only in the resistor — use the DC-style formula P=IR,rms2R in both series and parallel cases
