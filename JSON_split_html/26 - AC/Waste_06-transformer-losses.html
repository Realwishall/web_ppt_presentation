Alternating Current · Part 6

Transformer Losses

No real transformer hits 100% efficiency — here's where the energy actually goes.

Flux leakage & copper loss

Flux leakage
Issue:Not all of the flux created by the primary links the secondary coil — some "leaks" into the surrounding air
Fix:Wind primary and secondary tightly, one on top of the other, on the same core limb
Copper loss
Issue:Heating effect (I2R) in the resistance of the copper windings
Fix:Use thick wire / material of low resistance for the windings

Iron losses (in the core)

Eddy current loss
Issue:The changing flux induces circulating (eddy) currents within the solid iron core itself, heating it up
Fix:Use a laminated core — thin iron sheets insulated from each other, which breaks up the eddy current loops
Hysteresis loss
Issue:Energy is lost repeatedly magnetising and demagnetising the core every cycle — this is also the source of a transformer's humming noise
Fix:Use a core of soft iron, which has a narrow hysteresis loop and so loses less energy per cycle
Both are called "iron losses" because they happen inside the core, regardless of load

Summary — four loss mechanisms

  • Flux leakage — fixed by tight, close winding
  • Copper loss — fixed by low-resistance windings
  • Eddy current loss — fixed by a laminated core
  • Hysteresis loss — fixed by a soft-iron core
Together these keep real transformers around 95–99% efficient, not 100%
