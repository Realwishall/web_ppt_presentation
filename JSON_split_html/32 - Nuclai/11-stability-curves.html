The N–Z stability curve

  • Every nucleus on this curve is stable
  • Light nuclei sit near N : Z ≈ 1 : 1
  • Heavy nuclei climb to N : Z ≈ 3 : 2 (neutron rich)
  • Off the curve → tells the type of instability a nucleus has

Reason

Nuclear force is short range, so heavy nuclei need extra neutrons to overcome the long-range proton–proton repulsion.

Binding energy per nucleon

  • Maximum for Fe (56) → the most stable nucleus
  • Hydrogen B.E. can be taken as zero
  • Below 56: light nuclei fuse to climb the curve
  • Above 56: heavy nuclei split (fission) to climb the curve

Both directions move toward the peak → higher B.E./nucleon → more stability, energy released.

Everything in nature drifts toward the Fe-56 peak
