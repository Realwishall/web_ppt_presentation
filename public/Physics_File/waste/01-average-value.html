Alternating Current · Part 1

Average Value of AC

Over a full cycle a sine wave cancels itself out — so what does "average current" even mean?

Why average over a full cycle is zero

  • For i=i0sinωt, the positive half cycle and negative half cycle are mirror images
  • So over one full cycle, iavg=0
  • To get a useful number we take the average over one half cycle only
  • Definition: iavg=1T∫0Tidt
Equal and opposite areas → net area over a full cycle is zero

Average value over half a cycle

Question
For i=i0sinωt, find the average value from t=0 to t=T/2.
iavg=2T∫0T/2i0sinωtdt
⇒ iavg=2i0π≈0.637i0
Same result for voltage: V_avg = 2V₀/π

Special case — a shortcut worth knowing

  • The average value of a pure sine/cosine term over a full cycle is always zero — no matter its amplitude or phase
  • So if a signal has a constant (DC) part added to a sinusoid, only the constant survives on averaging: i=i1+i0sinωt⇒iavg=i1
  • Full-wave rectified current i=i0|sinωt| has the same average over every half cycle: 2i0π
Quick check
If i=3+7sinωt, what is iavg over a full cycle?
iavg=3 — the sine term drops out entirely
