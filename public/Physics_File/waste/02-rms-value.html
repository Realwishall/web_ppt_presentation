RMS Value

Root Mean Square — the "effective" steady value that would produce the same heating as the AC.

Root Mean Square value

  • irms is that steady (DC) current which produces the same heat in a resistor over one full cycle as the actual AC
  • Steps: Square the current → take the Mean over a cycle → take the Root
  • irms=1T∫0Ti2dt
  • Unlike the average value, i2 is never negative — so this doesn't vanish over a full cycle
Every AC ammeter/voltmeter you use in the lab actually reads the RMS value

RMS of a sinusoidal current

Question
Find irms for i=i0sinωt
⟨i2⟩=i02⟨sin2ωt⟩=i02·12
⇒ irms=i02≈0.707i0
Same for voltage: V_rms = V₀/√2  ·  ⟨sin²θ⟩ = ⟨cos²θ⟩ = ½ over a full cycle

RMS for other common waveforms

WaveformRMS value
Sinusoidal, peak i0i0/2
Square wave, peak i0i0 (same as peak)
Triangular / sawtooth, peak i0i0/3
Half-wave rectified, peak i0i0/2
A square wave has no "quiet" part — every instant is at full amplitude, so RMS = peak

Reading the meters

  • Whenever a value is "simply given" in a numerical without saying peak/rms, treat it as the RMS value — that's what meters and mains ratings quote (e.g. "220 V AC")
  • For V=100sinωt, the number 100 is the peak (amplitude) value, not RMS
  • All the phasor formulas built in the next chapters use amplitude (which can be swapped for RMS consistently) — never the instantaneous value
Mixing up peak and RMS is the single most common numerical mistake in this chapter
