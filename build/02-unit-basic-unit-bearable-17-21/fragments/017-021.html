Rule of SI

Unit in lower case

m, g, s — the symbol is written in small letters.

Upper case unit if on some scientist name

C, N, Pa, Wb, K

Coulomb, Newton, Pascal, Weber, Kelvin — the person gives the capital.

No plural unit

✗ Length of a rod is 10 ms

✓ Length of a rod is 10 m — a unit never takes an ‘s’.

No more than one solidus

✗ N/m/s/t

✓ N/(m s t) — one slash only; after that use brackets or negative powers.

Prefix without space

ms This is milli second
m s This is meter second — the space turned a prefix into a product.

Least Count

Least Count

Least count : The smallest value that can be measured on the instrument's scale.

Below it the instrument cannot tell you anything — you are estimating, not measuring.

Normal scale :
the smallest division you can read on a metre rule is 1 mm.
Least count = 1 mm = 0.1 cm
Normal scale — ten divisions to a centimetre, so one division is 1 mm

Screw gauge

Screw gauge : a micrometer — it measures thicknesses far below the 1 mm a metre scale can resolve.
Pitch : the distance the screw advances in one full turn of the thimble.

Screw gauge (parts)

Frame : the rigid U that holds the two jaws a fixed distance apart.
Stud : the fixed jaw; the object rests against it.
Screw : the moving spindle — one full turn advances it by one pitch.
Pitch scale : the millimetre scale printed along the sleeve.
Circular scale : the 100 divisions round the rim of the thimble.
Thimble : the barrel you turn to close the gap.
Ratchet : slips once the grip is right, so the object is never crushed.
One turn of the thimble drives the screw forward by one pitch
