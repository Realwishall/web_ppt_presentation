Fundamental/Derived
quantity and unit

Fundamental/Derived quantity and unit

Fundamental quantity

It is a set of quantity in which one quantity can not be derived by other quantity of this set.

And there unit is fundamental unit.

Derived quantity

All other quantity are derived quantity. They depend on more than one fundamental quantity.

And there unit is derived unit.

Test for a fundamental set Pick up any one member — if the other two can build it, the set fails.
